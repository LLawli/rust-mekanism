# rust-mekanism

Mods Java não rodam no [Horizon](https://playhorizon.dev/), a reescrita em Rust do Minecraft 26.3, então quem joga lá
fica sem o [Mekanism](https://github.com/mekanism/mekanism). Este projeto recria o Mekanism e o Mekanism Generators para
o Horizon, começando pelo início do jogo, e é para quem quer jogar ou ajudar a portar.

Ainda não há mod para instalar: o projeto está na fase de documentação.
